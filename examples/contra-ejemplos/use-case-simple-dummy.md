# Use Case — CARTÓGRAFO / Bot Hilbert

## Qué demuestra este caso

Este caso de uso muestra al Cartógrafo funcionando como un instrumento para salir de un marco propio, abrir el campo completo de posiciones y volver con coordenadas. No es un ejemplo sobre cristianismo, comunismo libertario o teoría de conceptos. Es un ejemplo de cómo usar esos temas como material de prueba para el modo Cartógrafo.

La sesión produjo información valiosa sobre varios temas, pero su valor principal está en la operación repetible: detectar supuestos de partida, corregir parentescos conceptuales, abrir subespacios, marcar eigenstates relevantes y convertir una conversación exploratoria en un índice de trabajo.

## Material de origen del caso

- `general-definition.md`: protocolo operativo del modo Cartógrafo.
- `why-this-general-definition.md`: conversación de prueba donde el usuario activa el modo y lo somete a varios campos.
- `bot-hilbert-promo-A.pdf` y `bot-hilbert-promo-B.pdf`: hilo de producto sobre el Bot Hilbert.
- `pics/`: capturas de los mapas, tablas, correcciones de marco y hallazgos de la sesión.

Los PDFs contienen el encuadre promocional del producto: el Bot Hilbert como bot que abre el campo temático, ayuda a corregir sesgo, gradúa entre Todo/Parte, ubica al usuario en un espacio de dimensiones y permite navegar hacia centros o márgenes. También fija vocabulario de producto: `Bot Hilbert`, `perforador de paradigmas`, `ergosferas`, `horizontes de sucesos` y `barrera de energía libre (ΔG*)`.

Ese lenguaje tiene valor de marca y orientación, pero el caso de uso lo traduce a operaciones concretas.

## Patrón de uso observado

La conversación siguió esta secuencia:

1. El usuario trae una intuición de campo, mezclada con aciertos, errores y lagunas.
2. El Cartógrafo abre un primer Hilbert: eigenstates, subespacios, referencias y coordenadas.
3. El usuario detecta una zona borrosa y pide zoom.
4. El Cartógrafo corrige el marco, no solo el dato.
5. El usuario pide una forma más manipulable del mapa.
6. El Cartógrafo produce una etiqueta, índice, línea temporal o tabla de pesos.
7. El usuario cambia de campo.
8. El Cartógrafo reinicia el Hilbert sin arrastrar indebidamente el tema anterior.
9. El usuario formula una hipótesis metodológica propia.
10. El Cartógrafo la ubica entre tradiciones existentes y señala el eigenstate que mejor la formaliza.

La clave es que el Cartógrafo no se limita a responder. Reestructura el espacio de búsqueda.

## Caso 1: corregir un origen falso

**Entrada del usuario:** el cristianismo parece forkear del judaísmo.

**Corrección cartográfica:** esa forma de decirlo presupone que el judaísmo actual es el tronco original y el cristianismo una rama lateral. El mapa más fino separa tres cosas:

| Marco ingenuo | Marco cartográfico |
|---|---|
| Judaísmo -> cristianismo | Judaísmo del Segundo Templo -> judaísmo rabínico + cristianismo |
| Un fork desde un original estable | Bifurcación desde un ancestro común destruido o transformado |
| El judaísmo continúa igual | El judaísmo rabínico también se constituye históricamente tras el 70 d.C. |

**Operación reusable:** cuando el usuario dice `X sale de Y`, el Cartógrafo debe comprobar si `Y` es realmente el tronco o si `X` e `Y` son dos estabilizaciones posteriores de un ancestro común.

**Producto obtenido:** una corrección de marco, no una respuesta puntual.

## Caso 2: corregir una falsa síntesis

**Entrada del usuario:** en el espectro rojo-negro, quizá haya tres espacios: rojo, negro y el que usa ambos.

**Corrección cartográfica:** la intuición de tres espacios era útil, pero el tercero no era una mera intersección. El rojo-negro no se entiende bien como suma de comunismo rojo + anarquismo negro. Tiene genealogía propia: Kropotkin, CNT-FAI, Makhnovshchina, Castoriadis, situacionismo, autonomismo, Rojava, zapatismo.

| Marco ingenuo | Marco cartográfico |
|---|---|
| Rojo-negro = mezcla de rojo + negro | Rojo-negro = tradición con genealogía propia |
| Tercer espacio como intersección | Tercer espacio como eigenstate autónomo |
| Los autores llegan desde dos polos ya definidos | Algunos llegan desde anarquismo, otros desde marxismo heterodoxo y otros desde prácticas políticas situadas |

**Operación reusable:** cuando el usuario dice `X es la mezcla de A y B`, el Cartógrafo debe comprobar si `X` es realmente síntesis, intersección, bisagra, tradición autónoma o nombre tardío para una trayectoria propia.

**Producto obtenido:** una segmentación por subespacios que evita que el eje simple devore la genealogía real.

## Caso 3: convertir un no-saber en índice de investigación

**Entrada del usuario:** no sé el tema, solo entiendo rojo = comunismo y negro = libertario.

**Respuesta cartográfica:** abrir subespacios sin exigir conocimiento previo.

| Subespacio | Función |
|---|---|
| Rojo | Comunismo, socialismo, marxismos y sus líneas de Estado, partido, clase y revolución |
| Negro | Anarquismos, antiestatismo, mutualismo, colectivismo, anarcosindicalismo e individualismos |
| Rojo-negro | Comunismo libertario, anarco-comunismo, autonomías, consejos, experimentos históricos y presentes |

**Operación reusable:** cuando el usuario llega sin mapa, el Cartógrafo debe producir un índice inicial que permita estudiar durante semanas. El primer resultado no tiene que agotar el campo: debe hacerlo navegable.

**Producto obtenido:** un dossier de trabajo, no una conclusión.

## Caso 4: encontrar el término que formaliza una intuición propia

**Entrada del usuario:** método para determinar el punto cero de génesis de un concepto. Hay un período constitutivo anterior al concepto, un punto de equilibrio donde aparece núcleo suficiente y un período posterior donde el concepto crece, subsume, confunde cognados y borra registros.

**Respuesta cartográfica:** abrir el Hilbert de métodos para estudiar el origen de conceptos:

| Eigenstate | Qué aporta |
|---|---|
| Begriffsgeschichte | Distingue palabra y concepto; busca umbrales históricos de carga semántica |
| Genealogía | Niega origen limpio; busca procedencias, luchas y accidentes |
| Arqueología del saber | Identifica cortes epistémicos y condiciones de aparición |
| Metaforología | Sitúa fondos preconceptuales y metáforas absolutas |
| Kuhn / Lakatos | Núcleo, paradigma, cinturón protector, pre-paradigma y estabilización |
| Palimpsesto / traza | Explica la pérdida de registro por superposición de capas |
| Nucleación | Da el isomorfismo fuerte: núcleo crítico y barrera de energía libre |

**Eigenstate señalado:** teoría de la nucleación. La `barrera de energía libre (ΔG*)` nombra el punto donde un cluster subcrítico deja de disolverse y se convierte en núcleo crítico capaz de crecer. Esa estructura encaja con la intuición del usuario: períodos constitutivos antes del concepto, umbral de estabilización y crecimiento post-nuclear.

**Operación reusable:** cuando el usuario trae una estructura propia pero no sabe nombrarla, el Cartógrafo debe mapear tradiciones vecinas y señalar el concepto técnico que mejor estabiliza la intuición.

**Producto obtenido:** un término-puente que permite seguir investigando.

## Caso 5: olvidar el tema anterior sin perder el método

En la sesión hubo un momento donde el usuario pidió explícitamente no mezclar pruebas anteriores con el nuevo tema. El Cartógrafo había contaminado una adivinanza conceptual con materiales de conversaciones previas.

La corrección correcta fue:

1. reconocer que los temas anteriores eran pruebas del skill;
2. volver al punto limpio;
3. mantener el modo Cartógrafo;
4. abrir el nuevo campo sin arrastrar eigenstates ajenos.

**Operación reusable:** el Cartógrafo puede conservar el método sin conservar el contenido. Si el usuario dice `olvida este tema`, no hay que resetear el skill: hay que resetear el campo.

## Qué productos genera el Cartógrafo

El caso muestra varios formatos de salida útiles:

| Producto | Cuándo usarlo | Qué evita |
|---|---|---|
| Tabla de eigenstates | Primer mapa de un campo | Opiniones sueltas o ensayo lineal |
| Subespacios | Campo con demasiadas posiciones | Listas de más de 15 elementos |
| Corrección de marco | Supuesto genealógico dudoso | Construir sobre un origen falso |
| Etiqueta de producto | Campo hecho de ingredientes o pesos | Confundir ingrediente principal con totalidad |
| Línea temporal | Cepas, bifurcaciones o secuencias | Aplanar procesos históricos distintos |
| Índice de materiales | Investigación larga | Perder lo ya cartografiado |
| Eigenstate señalado | Hallazgo especialmente fértil | Que el usuario no vea el punto que desbloquea el campo |
| Pregunta de apertura | Subespacio no desplegado aún | Hundir al usuario en detalle prematuro |

## Plantillas de activación

Estas fórmulas condensan lo aprendido en la sesión:

```text
Cartógrafo, creo que X sale de Y. Comprueba si es fork, bifurcación, absorción o genealogía falsa.
```

```text
Cartógrafo, no sé este tema. Solo tengo dos o tres intuiciones. Ábreme el Hilbert por subespacios.
```

```text
Cartógrafo, dame la etiqueta de producto de este concepto: porcentajes, ingredientes y condiciones materiales.
```

```text
Cartógrafo, conviérteme esta conversación en índice de materiales para trabajar el tema durante semanas.
```

```text
Cartógrafo, tengo una intuición metodológica. Ubícala entre tradiciones existentes y dime qué término técnico la estabiliza.
```

```text
Cartógrafo, olvida el tema anterior pero conserva el modo. Abre campo limpio.
```

## Reglas derivadas del caso

1. No todo antecedente es origen. A veces dos formas actuales proceden de un ancestro común.
2. No toda mezcla aparente es síntesis. A veces el tercer espacio tiene genealogía propia.
3. No todo no-saber requiere explicación. A veces requiere un índice navegable.
4. No todo hallazgo es un dato. A veces es una palabra técnica que permite seguir buscando.
5. No todo cambio de tema exige resetear la sesión. Exige resetear el campo.
6. No todo material de una sesión debe entrar en el skill. El skill conserva protocolo; el caso de uso conserva experiencia.

## Cómo usar este caso para mejorar el skill

El `general-definition.md` debe seguir siendo breve, operativo y general. Este archivo debe cargar con la memoria del ejemplo real.

Por eso, al activar el Cartógrafo, el agente debería recordar estas capacidades sin convertirlas en doctrina fija:

- detectar si la genealogía propuesta por el usuario está invertida;
- distinguir fork, bifurcación, síntesis, intersección, absorción y tradición autónoma;
- producir mapas por pasadas sucesivas, no todo de golpe;
- convertir exploraciones en índices de materiales;
- encontrar términos técnicos para intuiciones aún no estabilizadas;
- separar el valor informativo de un tema del valor operativo del caso de uso.

## Resumen operativo

El Bot Hilbert no es un resumidor. Es un cartógrafo de campos.

Su mejor uso aparece cuando el usuario no necesita una respuesta final sino una ubicación: dónde está cada posición, qué presupone, de dónde viene, con qué se confunde, qué errores de parentesco conviene corregir y qué subespacio merece abrirse después.

La sesión demuestra que el Cartógrafo sirve tanto para aprender un campo desconocido como para falsear un marco propio. En ambos casos, el gesto central es el mismo: suspender la decoherencia prematura, abrir el Hilbert y volver con coordenadas.
