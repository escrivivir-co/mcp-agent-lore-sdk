# Changelog

Todas las notas relevantes de este bloque se registran aquí siguiendo el espíritu de [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) y versionado semántico cuando tenga sentido operativo.

## [2.0.0] - 2026-05-31

### Added

- Bootstrap npm del bloque Bot-Hilbert como `@escrivivir-co/bot-hilbert`.
- Dependencia única `http-server` para servir el directorio `public/`.
- Scripts `public:web`, `public:web:open`, `audit:anchors` y `validate`.
- README principal para GitHub/npm con la doble superficie AgentLoreSDK + Bot-Hilbert v2.0.0.
- Documentación FOSS básica: contributing, security, changelog, PR template e issue templates.
- Skill `public-web` para que los agentes levanten un entorno web local para naves HTML.
- Directorio `public/` con landing local para visualizadores y assets estáticos.
- Documento de migración v1 -> v2 para `ARCHIVO/yo-no-soy-yo-propositions-engine`.

### Changed

- `README-SCRIPTORIUM.md` pasa de describir solo el submódulo AgentLoreSDK a presentar el bloque doble AgentLoreSDK + Bot-Hilbert v2.0.0.

### Migration

- El proyecto v1 queda valorado como candidato directo a primer dossier v2: `dossier-yo-no-soy-yo-v00-propositions-engine/`.
- La primera nave sugerida es un visualizador web de threads/eigenstates servido mediante `public-web`.
