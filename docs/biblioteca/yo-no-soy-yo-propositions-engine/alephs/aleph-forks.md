# Aleph — Forks del campo

**Capa:** todas  
**Módulo:** `aleph-forks`  
**Dossier:** `yo-no-soy-yo-propositions-engine`

> Esta capa inventaría los forks del campo, clasificados por símbolo operativo. Un fork es una operación sobre la filiación doctrinal entre eigenstates, no una opinión sobre su verdad.

---

## Leyenda de símbolos

| Símbolo | Operación | Descripción |
|---|---|---|
| `⊢` | Derivación legítima | El eigenstate fuente respalda explícitamente al derivado |
| `⊬` | Derivación bloqueada | El eigenstate fuente refuta al derivado (dato documental) |
| `⊘` | Extinciones / muertes | El referente ya no puede pronunciarse (muerte, cárcel) |
| `⥱` | Atribución retroactiva | Se atribuye al eigenstate fuente una posición que no enunció |
| `⟲` | Polémica intra-campo | Conflicto simétrico entre eigenstates sin árbitro documentado |
| `≈` | Cognación modern | Similitud estructural sin filiación directa |
| `†` | Fuente/persona fallecida | El eigenstate o autor referenciado ya no puede confirmar ni refutar |
