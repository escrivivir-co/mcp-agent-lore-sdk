## 0 · Por qué un mapa total y no sólo Thread 2

Thread 2 **no es un campo independiente**. Es una **operación de bloqueo** aplicada sobre una arista concreta del Thread 1: la `⥱ Marx → anarquismo` de Octavio. Si se cartografía Thread 2 como campo cerrado se pierde su función dialógica.

Este mapa hace zoom-out: mantiene el grafo del Thread 1 y muestra **dónde se enchufa Thread 2, qué arista intenta cortar, y qué nuevo fork abre al hacerlo**.

### Lectura

- Thread 2 **no** ataca el contenido sustantivo (¿era Marx anarquista?). Ataca la **operación de filiación misma**: usar el nombre propio para cerrar la identidad doctrinal. Es una refutación **un nivel arriba**.
- El precio: al hacerlo abre un nuevo problema cartográfico — *si Marx no es marxista, ¿qué es el marxismo y de quién procede?*. Esa pregunta es la que abre el mapa local de Thread 2 (ver [mapa-thread2-local.md](./mapa-thread2-local.md)).
