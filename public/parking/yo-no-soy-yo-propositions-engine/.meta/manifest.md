# Manifest Nave: yo-no-soy-yo-propositions-engine

- **Propósito**: Aplicación web de una sola página (SPA) dinámica para visualizar y explorar el `mapa.md` desde un dossier.
- **Cómo se lanza**: Servidor HTTP estático (`python -m http.server`) apuntando a la carpeta `nave/`. Abre `index.html`.
- **Formatos que abre**: Archivos Markdown y convierte a HTML dinámicamente usando `marked.js`.
- **Autor/Modelo**: Gemini 3.1 Pro (High) (2026-05-31)
- **Dependencias**: Navegador moderno, HTML5.
- **Tasa de cambio**: Estacionario.
